# SY Radioamateur exams

A single html webapp with reference and exam simulator for the entry-level radioamateur licence in Greece. The rest is for the locals...

## Περιγραφή

Αυτή η εφαρμογή δημιουργήθηκε με τη χρήση του Claude Code από το έγγραφο
`ΚΑΤΗΓΟΡΙΑ-ΕΙΣΑΓΩΓΙΚΟΥ-ΕΠΙΠΕ∆ΟΥ.pdf` και το κείμενο του `ΦΕΚ 1969 Α`, χωρίς χειροκίνητο προγραμματισμό.

Όλος ο κώδικας, το περιεχόμενο και οι εικόνες είναι hardcoded σε ένα μονολιθικό αρχείο html, για απλή και εύκολη χρήση.

Εάν εντοπίσετε ανακρίβειες ενημερώστε και εμένα για να τις ενσωματώσω.

Το αρχείο διανέμεται υπό CC BY-NC-SA.
